# CRM Callcentre — Выполненные улучшения

> Анализ и рефакторинг фронтенда колл-центра.

---

## Выполнено

### 1. Удалён мессенджер Авито
- Удалена страница `/messages`
- Удалены все компоненты: `MessageList`, `ChatList`, `ChatHeader`, и т.д. (16 файлов)
- Удалены хуки: `useChats`, `useMessages`, `useSocketMessages`, `useAutoRefresh`, `useAvitoAccounts`, `useAvitoEternalOnline`, `useAvitoReviews`, `useAvitoProxyCheck`, `useAvitoModals`
- Удалены типы: `types/avito.ts`
- Удалены admin-компоненты: `AvitoAccountForm`, `AvitoToolsSection`, `AvitoStatsCards`, `AvitoAccountsTable`, `ReviewsModal`, `ProxyCheckModal`, `EternalOnlineModal`, `DeleteAccountDialog`
- Удалён `AvitoNotificationListener` из `SocketProviders`
- Очищены ссылки в `useStaticData`, `query-optimized`, `validation-schemas`, `api-client`, `types/index`

### 2. Глобальный поиск по клиенту
- Новый компонент `GlobalSearch` в sidebar
- Поиск по телефону, имени клиента — результаты по заказам, звонкам, заявкам с сайта
- Горячая клавиша `Ctrl+K` для быстрого открытия
- Debounce 400ms, минимум 3 символа
- Навигация к нужному разделу по клику на результат

### 3. Quick Actions (альтернатива горячим клавишам)
- FAB-кнопка (Floating Action Button) на мобильных устройствах
- Быстрый доступ к: поиску, телефонии, заказам, обращениям, заявкам, статистике, справочнику
- `Ctrl+K` на десктопе для глобального поиска

### 4. Вкладка "Звонки" в карточке заказа
- Уже была реализована в `OrderViewModal` (вкладка `calls`)
- Показывает все звонки по номеру клиента с возможностью прослушивания

### 5. Индикатор итога звонка в телефонии
- Добавлены поля `orderId` и `appealId` в тип `Call`
- В `CallRowV4` показывается бейдж "Заказ #N" (зелёный) или "Обращение" (фиолетовый)
- Оператор сразу видит, обработан ли звонок

### 6. Напоминания о перезвоне
- Новый хук `useCallbackReminder` — проверяет заявки со статусом "Перезвонить" каждые 60 секунд
- Показывает toast-уведомление когда наступает время перезвона
- Кнопка "Открыть" в уведомлении ведёт на страницу заявок

### 7. Рефакторинг CreateOrderModal
- Разбит на подкомпоненты: `CallHistoryPanel`, `OrderHistoryPanel`, `AudioPlayerBar`
- Основной компонент уменьшен с ~960 строк до ~350
- Убрано дублирование поля РК (было 2 раза)
- Вынесены утилиты форматирования

### 8. Единая пагинация
- Страница site-orders переведена на `OptimizedPagination`
- Компонент `OptimizedPagination` уже используется в телефонии и заказах

### 9. Исправлен баг CallPushListener
- `isPushSubscribed` заменён на `isSubscribed: isPushSubscribed` (деструктуризация с алиасом)
- Теперь логика "не дублировать уведомления при включённом push" работает корректно

### 10. Стандартизация API
- Удалён `chatsApi` из `api-client.ts` (Авито удалён)
- Удалён `createFromChat` из `ordersApi`
- Удалён импорт `CreateOrderFromChatData`

### 11. Удалены дубликаты
- Удалён `useGroupedCalls.ts` — дублировал `useCallsData`, нигде не использовался
- Удалён `secure-storage.ts` — legacy, нигде не импортировался; `remember-me.ts` — актуальный backup storage

# CRM Callcentre — Предложения по улучшению

> Анализ проведён на основе полного изучения исходного кода фронтенда.

---

## Критические проблемы (мешают работе прямо сейчас)

### 1. Страница зарплаты — заглушка
- `/salary` показывает "Coming Soon"
- Сотрудник не видит свои начисления вообще
- **Что сделать:** реализовать хотя бы базовый просмотр начислений по периодам

### 2. Статистика слишком бедная
- На `/stats` отображается только количество звонков и заказов
- В типах (`OperatorStats`) уже есть поля `totalRevenue`, `conversionRate`, `averageOrderValue` — они нигде не выводятся
- **Что сделать:** добавить вывод конверсии, выручки, среднего чека

### 3. Мессенджер Авито (`/messages`) недоступен
- Страница полностью отключена ("на техобслуживании")
- Вся инфраструктура (типы, хуки, компоненты) готова в коде
- **Что сделать:** включить страницу обратно

---

## Рабочий процесс оператора — чего не хватает

### 4. Нет фиксации обращений без создания заказа
- Сейчас: оператор принимает звонок → либо создаёт заказ, либо ничего не записывается
- Если клиент позвонил с вопросом, передумал, попросил перезвонить — это нигде не фиксируется
- **Что сделать:** добавить модуль "Обращения" — отдельная сущность со своей воронкой:
  ```
  Новое → В работе → Ожидает клиента → Закрыто (решено) / Закрыто (отказ)
  ```
- Поля обращения:
  - Что хотел клиент (свободный текст + категория: вопрос / жалоба / заказ / консультация / перезвон)
  - Итог разговора
  - Статус
  - Привязка к звонку / чату / заявке с сайта / вручную
  - Привязка к заказу (если переросло)

### 5. В телефонии нет колонки "Итог звонка"
- После разговора оператор не видит в таблице — был ли создан заказ, добавлена заметка или ничего
- **Что сделать:** добавить в строку звонка индикатор — заказ создан / заметка / пусто

### 6. Заявки с сайта — только 3 статуса
- Текущие: `Создан → Не отвечает → Отказ`
- Слишком грубо для реальной работы
- **Что сделать:** добавить статусы:
  - "В обработке" — оператор взял в работу
  - "Перезвонить" — с указанием даты и времени перезвона

### 7. Нет напоминания о перезвоне
- Если оператор поставил "Не отвечает" — нет ни автоматического напоминания, ни дедлайна
- Заявка просто висит
- **Что сделать:** поле "Перезвонить до" + уведомление в нужное время

### 8. В карточке заказа нет истории звонков
- В `OrderViewModal` есть вкладки: Инфо, Документы, История
- Нет вкладки "Звонки" — посмотреть все звонки с этим номером из заказа нельзя
- Приходится вручную идти в телефонию и искать по номеру
- **Что сделать:** добавить вкладку "Звонки" в карточку заказа с фильтрацией по номеру клиента

## UX-проблемы интерфейса

### 9. Две версии интерфейса телефонии (V2 и V4)
- В коде живут `TelephonyPageV2`, `CallCard`, `CallsListView`, `CallDetailPanel` — но активна только V4-таблица
- V2 со своей боковой панелью удобнее: видишь список слева, детали справа без открытия модала
- **Что сделать:** либо убрать V2-мусор, либо вернуть как основной режим просмотра

### 10. Создание заказа из звонка — огромный монолитный модал
- `CreateOrderModal.tsx` в телефонии весит ~985 строк
- Один компонент делает всё сразу: историю заказов, аудиоплеер, форму
- **Что сделать:** разбить на подкомпоненты для читаемости и производительности

### 11. Нет глобального поиска
- Оператор не может быстро найти клиента по телефону и увидеть всё сразу: заказы, звонки, заявки
- **Что сделать:** единая строка поиска по номеру телефона — показывает всё по клиенту

### 12. Пагинация разная везде
- В заказах — одна реализация, в заявках с сайта — другая, в телефонии — третья
- **Что сделать:** единый переиспользуемый компонент `Pagination`

## Статистика — что можно улучшить

### 13. Нет почасовой загрузки
- Сотрудник не видит в какое время дня пик звонков
- Полезно для планирования перерывов и распределения нагрузки
- **Что сделать:** тепловая карта или график по часам дня

### 14. Нет сравнения с предыдущим периодом
- Только абсолютные цифры — непонятно, хорошо это или нет
- **Что сделать:** показывать дельту (+/-) относительно аналогичного предыдущего периода

### 15. Для администратора нет сводки по всем операторам
- Типы `OverallStats` и `OperatorStats` в коде есть, но нигде не используются на фронте
- Руководитель не видит сравнительную таблицу по операторам
- **Что сделать:** отдельный раздел статистики для роли `admin` с таблицей по операторам

## Мелкие, но заметные вещи

- Кнопка "Push включен/выключен" торчит прямо в панели уведомлений — технический элемент, нужно убрать в настройки профиля
- На мобильном часть функционала урезана без объяснения пользователю
- В таблице заказов нет быстрого действия "позвонить" — только просмотр номера
- Нет горячих клавиш нигде в приложении
- Дублирующиеся хуки: `useCallsData` и `useGroupedCalls` делают одно и то же
